# Youtube Clone

### ✨ About

I based this clone I made on the course I took (this project was one of the learning exercises). The original clone was based on the older version of YouTube, so I did it differently and drew inspiration from the new version of YouTube.

### 💡 What i learned

- Learn about font types and how to choose them correctly
- Learn more about SVGs, how to use them, and how to edit them
- Use the `div` element only when truly necessary
- How to combine the links for each channel and thumbnail
- The use of entities: what they’re for and what other types there are
- Flexbox and Grid to create a harmonious layout for the website
